ChatGPT and Codex are different products, and only one of them can install a skill. Codex reads a skills folder on your machine, so the one-command install works there. The ChatGPT chat window has no filesystem, so nothing can be installed into it. You port the skill instead, as a Custom GPT.

1

Download the skill

Grab the repo as a zip from GitHub and unzip it, or clone it if you are comfortable with that.

2

Create a Custom GPT

In ChatGPT, open the sidebar, then GPTs, then Create. Give it the name defi-native.

3

Paste the instructions

Copy chatgpt/INSTRUCTIONS.md from the repo into the Instructions box. It is a condensed version of the skill's brain, trimmed to fit the character limit ChatGPT puts on that field.

4

Upload the reference files as Knowledge

Under Knowledge, upload SKILL.md, everything in references/, plus manifest.json and api-routes.json. That is 19 files against ChatGPT's limit of 20. Running python3 scripts/pack_chatgpt.py collects them into one folder for you.

5

Turn on Web Search

Under Capabilities. Without it the skill cannot pull live numbers, and dating every number is half of what it does.

A Project works too if you would rather not build a GPT: create one, put the same text in the project instructions and upload the same files. Either way you get the mental models and the discipline. What you do not get is the automatic loading, so say use defi-native when you want it.

Clone it and link it in. This is also the install that can keep itself updated.

manual install

$git clone https://github.com/emlai/defi-native-skill.git ~/code/defi-native-skill

$ln -s ~/code/defi-native-skill ~/.agents/skills/defi-native

~/.agents/skills/ is the shared folder most hosts read. Claude Code also reads ~/.claude/skills/, so link it into both if you use several agents.

Optional API keys unlock deeper data but are never required. Plug in your own keys if you would like even more robust answers.

06 Questions

Questions

What is defi-native?

defi-native is a folder of plain text files you drop into an AI agent to make it expert at one thing: everything onchain finance. It includes specific instructions, reference material, and worked examples. It's free to install and works with any AI.

Who is defi-native for?

defi-native is for:

1. Anyone who trades onchain and uses defi protocols
2. Anyone who wants to learn traditional and onchain finance concepts

Does it only work with Claude or ChatGPT?

No. Any agent that reads the Agent Skills format: Claude Code, Cursor, Codex, Grok Bot and others.

How to install

Do I need API keys?

No. Everything core runs keyless. Keys buy you deeper data, and the skill will name the one key that would improve the answer in front of you. You can install in 30 seconds.

Can it move my money?

No. defi-native was built to help the team understand financial concepts and the latest in defi. It cannot trade for you, does not have access to your wallet, and can never sign, submit or approve a transaction.

It can be used to help with investment decisions, understanding where the yield comes from, and sizing opportunities.

How much does it cost?

defi-native is completely free and always will be.

Is there a token?

The Bankr community launched a token based off this AI skill announcement on X. Fees are used to fund the project. Some fees have also been airdropped to holders. The defi-native team owns zero tokens.

Is this financial advice?

No. It produces research, and says so every time. Ask for a pick and you will get one, but only with the full view attached: what has to be true, what breaks it, the total loss case, and the runner up. DeFi has total loss tails and the skill never pretends otherwise.

1.8.0
2026-09-02

It can now tell you whether a tokenized fund's yield is real. Putting money into a tokenized treasury or credit fund is not like buying a token on an exchange. Someone decides the price you come in at, and when they decide it can work for you or against you. This covers the four ways that settlement actually happens, how to tell whether an advertised yield was measured or simply announced, and what the issuer takes before any of it reaches you. Contributed by @mishablank.

Also added: how attention turns into an asset, a new kind of lending market where your interest rate is really a bid for your place in the exit queue, and how to read raw blockchain logs when the dashboards do not go back far enough.
